05. DOM Forms (Properties & Events)

← Back to Week 3

1. Accessing Form Elements

const form = document.querySelector("form");
const nameInput = document.getElementById("name");
const emailInput = document.querySelector("#email");

// Get values
nameInput.value
emailInput.value

// Set values
nameInput.value = "Muhammad Kashif";

2. Important Form Properties & Methods

// Common properties
input.value          // current value
input.checked        // for checkbox/radio
input.disabled       // disable field
input.placeholder
input.type
select.selectedIndex
select.value

// Methods
form.reset()         // clear all fields
form.submit()        // submit the form
input.focus()
input.blur()

3. Form Events

// Most used events
form.addEventListener("submit", function(e) {
    e.preventDefault();   // stop page reload
    // handle data
});

input.addEventListener("input", ...)     // every keystroke
input.addEventListener("change", ...)    // when value changes & loses focus
input.addEventListener("focus", ...)
input.addEventListener("blur", ...)
