1. What is an Object?

Objects are used to store related data and functionality together in key-value pairs.

const student = {
    name: "Kashif",
    age: 22,
    isStudent: true,
    skills: ["HTML", "CSS", "JavaScript"]
};

2. Creating Objects

// Object Literal (most common)
const person = { name: "Ali", age: 25 };

// Using new Object()
const car = new Object();
car.brand = "Toyota";
car.model = "Corolla";

// Using Object.create()
const animal = Object.create(null);
animal.type = "Dog";

3. Accessing Properties

const user = {
    firstName: "Muhammad",
    lastName: "Kashif",
    "full-name": "Muhammad Kashif"
};

// Dot Notation
console.log(user.firstName);     // Muhammad

// Bracket Notation (required for special characters or dynamic keys)
console.log(user["lastName"]);   // Kashif
console.log(user["full-name"]);  // Muhammad Kashif

const key = "firstName";
console.log(user[key]);          // Muhammad

4. Adding, Updating & Deleting Properties

const product = { name: "Laptop", price: 50000 };

// Add new property
product.brand = "Dell";
product["color"] = "Black";

// Update
product.price = 48000;

// Delete
delete product.color;
