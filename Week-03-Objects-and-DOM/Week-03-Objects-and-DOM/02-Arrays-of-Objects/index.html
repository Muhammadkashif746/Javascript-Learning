02. Arrays of Objects

← Back

1. Why Arrays of Objects?

When we need to store large amounts of related data (like students, products, users), we use an Array of Objects.

const students = [
    { id: 1, name: "Ali", age: 20, marks: 85 },
    { id: 2, name: "Sara", age: 21, marks: 92 },
    { id: 3, name: "Ahmed", age: 19, marks: 78 }
];

2. Storing Large Data Example

const products = [
    { id: 101, name: "Laptop", price: 85000, brand: "Dell", inStock: true },
    { id: 102, name: "Mobile", price: 45000, brand: "Samsung", inStock: true },
    { id: 103, name: "Headphones", price: 3500, brand: "Sony", inStock: false },
    { id: 104, name: "Keyboard", price: 2500, brand: "Logitech", inStock: true },
    { id: 105, name: "Mouse", price: 1200, brand: "HP", inStock: true }
];

3. Common Operations

// Access single object by index
console.log(products[0]);           // First product
console.log(products[0].name);      // "Laptop"

// Loop through all objects
products.forEach(product => {
    console.log(product.name, product.price);
});

// Get only names
const names = products.map(p => p.name);

// Filter in-stock products
const available = products.filter(p => p.inStock);
