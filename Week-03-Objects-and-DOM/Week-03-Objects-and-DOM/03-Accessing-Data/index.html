03. Accessing Data (Different Methods)

← Back

1. Dot Notation vs Bracket Notation

const user = {
    name: "Kashif",
    age: 22,
    "user-id": 746,
    skills: ["JS", "React"]
};

// Dot Notation (simple & clean)
user.name
user.age

// Bracket Notation (required when key has special characters or is dynamic)
user["user-id"]
user["skills"]

const key = "name";
user[key]          // Dynamic access

2. Accessing Array of Objects

const users = [
    { id: 1, name: "Ali", role: "Admin" },
    { id: 2, name: "Sara", role: "User" },
    { id: 3, name: "Ahmed", role: "Moderator" }
];

// By Index
users[0]
users[0].name

// By filter / find
users.find(u => u.id === 2)
users.filter(u => u.role === "User")

// By map (transform)
users.map(u => u.name)

3. Useful Methods for Accessing Data

  • find() → returns the first matching object
  • filter() → returns array of all matching objects
  • map() → creates new array by transforming each item
  • some() → checks if at least one item matches
  • every() → checks if all items match
  • reduce() → useful for calculations (sum, max, min)
