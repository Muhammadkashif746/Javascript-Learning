04. DOM Basics & Manipulation

← Back

1. What is the DOM?

DOM (Document Object Model) is the programming interface for HTML. JavaScript can use it to change content, structure, and style of a webpage.

2. Selecting Elements

// By ID
document.getElementById("myId")

// By Class
document.getElementsByClassName("myClass")

// By Tag
document.getElementsByTagName("p")

// Modern & Preferred
document.querySelector("#myId")
document.querySelector(".myClass")
document.querySelectorAll("p")

3. Changing Content & Style

const heading = document.querySelector("h1");

// Change text
heading.textContent = "New Heading";
heading.innerHTML = "New Heading";

// Change style
heading.style.color = "blue";
heading.style.backgroundColor = "yellow";

// Add / Remove Class
heading.classList.add("active");
heading.classList.remove("active");
heading.classList.toggle("dark");

4. Creating & Adding Elements

// Create
const newDiv = document.createElement("div");
newDiv.textContent = "I am new!";
newDiv.className = "card";

// Add to page
document.body.appendChild(newDiv);

// Insert before another element
parent.insertBefore(newDiv, existingElement);
