# 🧮 Calculator App

A simple, sleek, and fully responsive calculator built with **HTML5**, **Tailwind CSS**, and **JavaScript**.
This project was developed as part of my **CodeAlpha Internship** tasks.

---

## ✨ Features

- 🎯 **Accurate Real-Time Calculations** — supports addition, subtraction, multiplication, and division
- 🎨 **Modern UI** — clean, minimal design built with Tailwind CSS
- 📱 **Fully Responsive** — works seamlessly on desktop, tablet, and mobile
- ⚡ **Fast & Lightweight** — no frameworks, pure JavaScript logic
- 🧹 **Clear & Delete Functions** — easily reset or correct inputs
- ⌨️ **Smooth Button Interactions** — intuitive and easy to use

---

## 🛠️ Built With

- **HTML5** — structure and layout
- **Tailwind CSS** — modern, responsive styling
- **JavaScript** — calculator logic and functionality
