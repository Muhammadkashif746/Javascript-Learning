Variables in JavaScript (ES5 vs ES6)

← Back

1. var (ES5 - Old Way)

// Function scoped, can be redeclared and updated
var name = "Ali";
var name = "Ahmed";   // No error (redeclaration allowed)
name = "Khan";        // Can be updated

console.log(name);

2. let (ES6 - Modern)

// Block scoped, cannot be redeclared but can be updated
let age = 20;
age = 21;           // OK - updating value
// let age = 22;    // Error - cannot redeclare

3. const (ES6 - Best for constants)

// Block scoped, cannot be redeclared or updated
const PI = 3.14;
// PI = 3.1416;     // Error!
const student = { name: "Sara" };
student.name = "Ayesha";   // OK (object properties can change)
