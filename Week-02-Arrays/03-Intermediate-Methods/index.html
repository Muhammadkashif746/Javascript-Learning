03. Intermediate Array Methods

← Week 2 Home

1. slice() - Extract portion without modifying original

const numbers = [1, 2, 3, 4, 5, 6];
const sliced = numbers.slice(1, 4);     // from index 1 to 3
const lastTwo = numbers.slice(-2);      // last 2 elements

2. splice() - Add/Remove/Replace elements (modifies original)

const fruits = ["Apple", "Banana", "Mango", "Orange"];

// Remove 1 item at index 2
fruits.splice(2, 1);

// Add new items at index 1
fruits.splice(1, 0, "Kiwi", "Pineapple");

3. Searching Methods

const arr = ["Ali", "Sara", "Ahmed", "Sara"];

// indexOf, lastIndexOf, includes
arr.indexOf("Sara");        // 1
arr.lastIndexOf("Sara");    // 3
arr.includes("Ahmed");      // true
