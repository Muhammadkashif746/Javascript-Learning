1. What is an Array?

Arrays are used to store multiple values in a single variable. They are ordered and can hold any data type.

const numbers = [10, 20, 30];
const names = ["Ali", "Sara", "Ahmed"];
const mixed = [1, "text", true, null];

2. Array Properties

const arr = [5, 10, 15];
console.log(arr.length);        // 3
console.log(arr[0]);            // 5 (first item)
console.log(arr[arr.length-1]); // last item
