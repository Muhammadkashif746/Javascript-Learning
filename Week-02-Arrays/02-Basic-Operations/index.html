02. Basic Array Operations

← Week 2 Home

1. Adding Elements

// push()  - Add to the END
// unshift() - Add to the START

let tasks = ["Learn JS"];
tasks.push("Practice Arrays");        // Add at end
tasks.unshift("Revise Week 1");       // Add at start

console.log(tasks);

2. Removing Elements

// pop()   - Remove from END
// shift() - Remove from START

tasks.pop();     // Removes last item
tasks.shift();   // Removes first item

3. length Property

console.log(tasks.length);
tasks.length = 2;     // Truncate array
tasks[tasks.length] = "New Item";  // Add using length
